## Features

- Responsive design using HTML5 and the viewport meta tag
- A clean, organized layout styled with internal CSS
- Semantic HTML elements for structure and accessibility

## Sections Included

### 1. Navigation Bar
A simple horizontal navigation bar with links to:
- Home
- About
- Contact

### 2. Contact Form
A basic contact form that includes:
- Name (text input)
- Email (email input)
- Message (textarea)
- Submit button

### 3. Product Table
A table displaying example product information with the following columns:
- Product Name
- Price
- Quantity

Includes three sample products.
